## Featured project: Nexus

A production-style platform on AWS that I designed and built end to end, split
across three repositories the way a team would own it:

| Repository | What it covers |
| --- | --- |
| [nexus-platform](https://github.com/SergeAbroyan/nexus-platform) | AWS with Terraform and Terragrunt: EKS, RDS, ElastiCache, SQS, CloudFront and WAF, active-passive regions |
| [nexus-gitops](https://github.com/SergeAbroyan/nexus-gitops) | Argo CD, Istio, Karpenter, Kyverno, Argo Rollouts canaries, Prometheus, Loki, Tempo, Velero |
| [nexus-applications](https://github.com/SergeAbroyan/nexus-applications) | Go API and Java worker with a signed supply chain: Testcontainers, Trivy, cosign, SBOMs, OpenTelemetry |

A walkthrough with screenshots from a live environment is on
[sergeabroyan.com/projects/nexus](https://sergeabroyan.com/projects/nexus/).
